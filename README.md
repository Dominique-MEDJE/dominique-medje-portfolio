## 🎨 Design

- Dark UI inspiré du style Dribbble
- Typographies : **Urbanist** & **Outfit** (Google Fonts)
- Palette : `#0E0E0E` hero · `#151515` sections · `#F05A2E` accent
- Effets `-webkit-text-stroke` pour textes contour (outline)
- Fenêtre centrée 88% avec coins arrondis sur fond orange `#FF7A3D`
- Responsive Mobile / Tablet / Desktop

## 🚀 Sections

1. **Header** — Logo `Mahuna.` + navigation numérotée (01–06)
2. **Hero** — SANTÉ PUBLIQUE & GESTION DE PROJET 360° + portrait
3. **01 À propos** — Citation + orbite animée + bouton CV
4. **02 Compétences** — Grille de cartes skills
5. **03 Projets** — 5 projets capstone
6. **04 Expérience** — Timeline verticale
7. **05 Formation** — Diplômes + 8 certifications
8. **06 Contact** — Canaux de contact + footer

## 🛠️ Technologies

- HTML5 sémantique
- CSS3 (variables, grid, flexbox, animations)
- JavaScript vanilla (ScrollSpy, parallax, menu mobile)
- Zéro framework externe
